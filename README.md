# Mohanvamsi Vura - Azure Data Engineer Portfolio

A premium, modern personal portfolio built with React, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion (motion/react)](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Inter & Space Grotesk

## 📂 Project Structure

- `src/data.ts`: Central source of truth for resume content.
- `src/App.tsx`: Main application architecture and components.
- `src/index.css`: Custom theme and glassmorphism utilities.

## ✨ Features

- **Responsive Design**: Mobile-first approach for all sections.
- **Glassmorphism UI**: High-end aesthetic with background blurs and gradient accents.
- **Interactive Timeline**: Visualizing career progression at TCS.
- **Skill Arsenal**: Categorized technical expertise.
- **Contact Integration**: Accessible communication channels and form.

## 🛠️ Setup

1. The app is pre-configured and ready to run.
2. To update content, modify `src/data.ts`.
3. Styles can be tuned in `src/index.css`.
